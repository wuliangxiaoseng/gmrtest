## 零、参考资料

### 0.1 国密规范详解文档

**文档位置**：`docs/GMT0005随机性检测规范详解.md`

**主要内容**：

| 章节 | 内容 | 实现应用 |
|------|------|---------|
| 二、整体检测参数 | 样本集容量、显著性水平、通过率阈值 | 确定默认配置参数 |
| 三、15种检测方法详解 | 每种检测的原理、参数、统计量、p值计算公式 | **核心算法实现参考** |
| 四、三级样本长度 | 20K/1M/100M bit 对应参数差异 | 参数配置依据 |
| 五、27项独立检测清单 | 所有检测项的完整列表 | 确定待实现项数量 |
| 六、双重判定准则 | P_value + Q_value 计算 | 结果输出格式 |
| 七、2021版vs2012版差异 | 参数变化、新增检测项 | 确保符合最新规范 |

**关键技术要点**：

1. **参数规范**：
   - 块内频数检测：m = 10000（2021版）
   - 扑克检测：m = 4, m = 8
   - 重叠子序列检测：m = 3, m = 5（2021版）
   - 块内最大游程检测：m = 10000
   - 线性复杂度检测：m = 500, m = 1000

2. **p值计算公式**：
   - 卡方分布型：`igamc(df/2, χ²/2)`
   - 正态分布型：`erfc(|V|/√2)`

3. **Q值计算**：
   - 卡方分布型：Q_value = P_value
   - 正态分布型：`erfc(V_raw/√2)`（不取绝对值）

## 二、详细操作步骤

### 2.1 阶段一：需求分析

**输入**：检测算法需求（国密规范/NIST标准）

**输出**：需求文档、参数清单

**操作要点**：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 确认算法来源 | 国密 GM/T 0005-2021 或 NIST SP 800-22 |
| 2 | 提取算法参数 | 块大小、窗口大小、显著性水平等 |
| 3 | 确定输出格式 | 单结果/多结果（如serial检测返回P1/P2） |
| 4 | 记录数学函数依赖 | erfc, igamc, lgam 等 |

### 2.2 阶段二：接口设计

**输入**：需求文档

**输出**：函数签名、测试项ID定义

**操作要点**：

#### 2.2.1 函数签名规范

```c
TestStatus test_<test_name>(const BitData *data, int n, 
                            TestResult *result, const TestConfig *config);
```

**参数说明**：
- `data`: 比特数据（位压缩存储）
- `n`: 序列长度（比特数）
- `result`: 测试结果输出结构
- `config`: 测试配置（包含 alpha、block_length 等参数）

**返回值**：`TEST_SUCCESS`, `TEST_FAILURE`, `TEST_ERROR`

#### 2.2.2 测试项ID命名规范

```
<算法名>[-参数]

示例:
frequency                    # 无参数
block_frequency-m=10000     # 带参数
poker-m=4                   # 带参数
longest_run-m=10000,ones    # 多参数用逗号分隔
```

### 2.3 阶段三：代码实现

**输入**：接口设计文档

**输出**：`src/tests/<test_name>.c`

**操作要点**：

#### 2.3.1 文件模板

```c
#include <math.h>
#include "tests.h"
#include "utils.h"

TestStatus test_<test_name>(const BitData *data, int n, 
                            TestResult *result, const TestConfig *config)
{
    // 1. 参数验证
    if (data == NULL || result == NULL || n <= 0) {
        return TEST_ERROR;
    }
    
    // 2. 设置结果基本信息
    result->id = "<test_id>";
    result->name = "<中文名称>";
    
    // 3. 算法实现
    // ... 核心检测逻辑 ...
    
    // 4. 设置结果
    result->p_value = p_value;
    result->q_value = p_value;  // 二级检测使用
    result->stat_value = stat_value;
    
    // 5. 判断结果
    if (p_value < config->alpha) {
        result->status = TEST_FAILURE;
        result->message = "p值小于显著性水平";
        return TEST_FAILURE;
    }
    
    result->status = TEST_SUCCESS;
    result->message = "通过";
    return TEST_SUCCESS;
}
```

#### 2.3.2 位访问方式

```c
// 使用预定义宏访问比特
int bit = GET_BIT(data, index);
```

#### 2.3.3 数学函数调用

```c
// 互补误差函数
double erfc_val = math_erfc(x);

// 互补不完全Gamma函数
double igamc_val = math_igamc(a, x);

// Gamma函数对数
double lgam_val = math_lgam(x);
```

### 2.4 阶段四：系统集成

**输入**：实现代码

## 三、关键注意事项

### 3.1 常见陷阱

| 陷阱 | 表现 | 规避方法 |
|------|------|---------|
| 数组越界 | 配置项不生效、程序崩溃 | 数组大小预留充足余量 |
| TEST_COUNT 不匹配 | 新增测试项无法被调用 | 每次添加后更新计数 |
| 算法实现错误 | p值异常（0或>1） | 参考原项目验证过的实现 |
| 参数解析错误 | 测试项无法被正确识别 | 仔细检查配置项命名匹配 |

### 3.2 最佳实践

#### 3.2.1 代码组织
- 文件命名：`test_<name>.c`
- 函数命名：`test_<name>`
- 错误处理：每个函数开头进行参数验证

#### 3.2.2 配置系统
- 配置项命名：`<算法名>-<参数>`
- 默认参数：在 `config.h` 中定义
- 配置文件格式：INI格式

#### 3.2.3 集成流程
- 增量集成：先编写桩实现，再逐步完善
- 测试驱动：每完成一个模块立即测试
- 文档同步：代码变更后及时更新文档

## 五、示例：添加新检测项的具体操作

以添加"示例检测"为例：

### 步骤1：创建实现文件

```bash
touch src/tests/example.c
```

### 步骤2：添加函数声明

编辑 `include/tests.h`：
```c
TestStatus test_example(const BitData *data, int n, 
                        TestResult *result, const TestConfig *config);
```

### 步骤3：注册测试项

编辑 `src/gmrtest.c`：
```c
{"example", "示例检测", "示例检测描述", test_example, NULL, 1000},
```

### 步骤4：添加配置支持

编辑 `src/main.c`：
```c
// 在 config_entries 中添加
{"example", "example", "", "示例检测"},
```

### 步骤5：更新编译配置

编辑 `Makefile`：
```makefile
SRCS_TESTS  = ... \
              $(SRC_DIR)/tests/example.c \
              ...
```

### 步骤6：更新常量

编辑 `include/config.h`：
```c
#define TEST_COUNT                      21  // 增加1
```

### 步骤7：编译测试

```bash
make && ./bin/gmrtest -f test/random.bin -t example
```

## 六、问题排查指南

### 6.1 编译错误

| 错误类型 | 常见原因 | 解决方案 |
|---------|---------|---------|
| 未定义的引用 | 函数未实现或未链接 | 检查 Makefile 和函数定义 |
| 类型不匹配 | 参数类型错误 | 检查函数签名 |
| 重复定义 | 头文件重复包含 | 使用 include guard |

### 6.2 运行错误

| 错误类型 | 常见原因 | 解决方案 |
|---------|---------|---------|
| p值=0或>1 | 算法实现错误 | 参考原项目实现 |
| 测试项不生效 | 配置未正确加载 | 检查配置项名称和数组大小 |
| 程序崩溃 | 数组越界 | 检查数组大小和索引 |
