# GM/T 0005-2021《随机性检测规范》详解

## 一、标准基本信息

- **标准号**：GM/T 0005-2021
- **名称**：随机性检测规范（Randomness test specification）
- **发布单位**：国家密码管理局
- **实施日期**：2022 年 5 月 1 日
- **替代标准**：GM/T 0005-2012
- **适用范围**：对随机数发生器产生的二元序列进行随机性检测
- **起草单位**：国家密码管理局商用密码检测中心、中国科学院软件研究所、中国科学院信息工程研究所、北京宏思电子技术有限责任公司、浙江大学

---

## 二、整体检测参数

| 参数     | 规定值                               | 说明                                           |
|--------|------|---------|
| 样本集容量 | **1000 个**序列 | 每次检测需准备 1000 个独立样本 |
| 通过率显著性水平 α | **0.01** | 单个样本 P_value 的阈值 |
| 均匀性显著性水平 α' | **0.0001** | 2021 版新增，Q_value 卡方检验显著水平 |
| 样本长度 | **20,000 / 1,000,000 / 100,000,000 bit** | 2021 版新增三级规范 |
| 通过率阈值 | **≥ 981/1000** | P_value ≥ 0.01 的样本占比 ≥ 98.1% |
| 均匀性分箱数 k | **10** | Q_value 卡方检验的等宽区间数 |

## 三、15 种检测方法详解（以 1,000,000 bit 样本为例）

### 3.1 单比特频数检测 (Mono-Bit Frequency Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列中 0 和 1 的个数是否接近，即均衡性 |
| 原理 | 将 0/1 映射为 -1/+1 后累加，统计量 V = S_n / √n 服从标准正态分布 N(0,1) |
| 参数 | 无 |
| P_value | `erfc(\|V\| / √2)` |
| Q_value | `erfc(V / √2)`（2021 版新增，用原始值而非绝对值） |
| 分布类型 | 正态分布型 |

### 3.2 块内频数检测 (Frequency Test Within a Block)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | m 位子序列中 1 的比例是否接近 m/2 |
| 原理 | 将序列划分为 N 个长度为 m 的非重叠块，统计每个块中 1 的比例，构造 χ² 统计量 |
| 参数 | **m = 10,000**（2021 版从 m=100 改为 m=10000，便于字节对齐） |
| 约束 | n ≥ 100m |
| P_value / Q_value | `igamc(N/2, V/2)`（卡方型，P = Q） |
| 分布类型 | 卡方分布型 |

### 3.3 扑克检测 (Poker Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 2^m 种 m 位子序列模式的出现频率是否均匀 |
| 原理 | 划分 N 个长度为 m 的非重叠子序列，统计每种 m 位模式出现的频数，构造 χ² 统计量 |
| 参数 | **m = 4, m = 8**（2 个独立检测项） |
| P_value / Q_value | `igamc((2^m - 1)/2, V/2)`（卡方型） |
| 分布类型 | 卡方分布型 |

### 3.4 重叠子序列检测 (Overlapping Template Matching Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 可重叠的 m 位子序列模式分布的均匀性 |
| 原理 | 将前 m-1 位附加到序列末尾构成新序列，统计 m、m-1、m-2 位模式的频数，计算 ∇Ψ²_m 和 ∇²Ψ²_m 两个统计量 |
| 参数 | **m = 3, m = 5**（2021 版由 m=2,5 改为 m=3,5） |
| 独立检测项 | 共 4 项：m=3 的 P_value1/P_value2 + m=5 的 P_value1/P_value2 |
| P_value | 两个 P_value（均需 ≥ α） |
| Q_value | 两个 Q_value（正态分布型） |
| 分布类型 | 正态分布型 |

### 3.5 游程总数检测 (Runs Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列中游程总数是否符合随机性要求（游程 = 连续相同比特） |
| 原理 | 统计总游程数 V_n(obs)，与期望值 2nπ(1-π)+1 比较 |
| 参数 | 无 |
| P_value | `erfc(\|V_n(obs) - 2nπ(1-π)\| / (2√(2n)·π(1-π)))` |
| Q_value | 同上，但不取绝对值（正态分布型） |
| 分布类型 | 正态分布型 |

### 3.6 游程分布检测 (Runs Distribution Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 不同长度游程的分布是否均匀 |
| 原理 | 确定最大整数 k 使期望频数 e_i ≥ 5，统计各长度游程数目，构造 χ² 统计量 |
| 参数 | 无 |
| 2021 版变化 | **统计量 ei 改用实际总游程数计算**（2012 版按理想值，误差较大）。长度超过 k 的游程分别计入 b_k 和 g_k |
| P_value / Q_value | `igamc(k-1, V/2)`（卡方型） |
| 分布类型 | 卡方分布型 |

### 3.7 块内最大游程检测 (Longest Run of Ones in a Block)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 每个 m 位块内的最大 1 游程（和 0 游程）长度分布 |
| 原理 | 将序列分为 N 个 m 位块，按区间统计最大游程长度频数，χ² 检验 |
| 参数 | **m = 10,000** |
| 2021 版变化 | 新增块内最大 0 游程检测（与 1 游程并列，共 2 个独立检测项）；πi 值修订 |
| P_value / Q_value | `igamc(K/2, V/2)`（卡方型） |
| 分布类型 | 卡方分布型 |

**πi 值对比（m=10000 时）**：

| πi      | 2012 版 | 2021 版   |
|-------|--------|----------|
| π₀ | 0.0882 | 0.086632 |
| π₁ | 0.2092 | 0.208201 |
| π₂ | 0.2483 | 0.248419 |
| π₃ | 0.1933 | 0.193913 |
| π₄ | 0.1208 | 0.121458 |
| π₅ | 0.0675 | 0.068011 |
| π₆ | 0.0727 | 0.073366 |

### 3.8 二元推导检测 (Binary Derivative Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 对序列逐次异或推导后，检验推导序列的随机性 |
| 原理 | 连续 k 次异或相邻比特得到推导序列，再对推导序列执行单比特频数检测 |
| 参数 | **k = 3, k = 7**（2 个独立检测项） |
| P_value / Q_value | 正态分布型 |
| 分布类型 | 正态分布型 |

### 3.9 自相关检测 (Autocorrelation Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列是否存在自相关性（周期特征） |
| 原理 | 将序列与自身平移 d 位后异或，统计不一致的比特数，构造正态统计量 |
| 参数 | **d = 1, 2, 8, 16**（4 个独立检测项） |
| P_value / Q_value | 正态分布型 |
| 分布类型 | 正态分布型 |

### 3.10 矩阵秩检测 (Matrix Rank Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列构成的矩阵的秩分布是否与随机序列一致 |
| 原理 | 将序列排列成 32×32 矩阵，计算 GF(2) 上的秩，统计满秩/降秩比例，χ² 检验 |
| 参数 | M = 32, Q = 32 |
| P_value / Q_value | 卡方型 |
| 分布类型 | 卡方分布型 |

### 3.11 累加和检测 (Cumulative Sum Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列累加和的最大偏移量是否过大 |
| 原理 | 0→-1, 1→+1 后逐比特累加，取最大绝对值作为统计量 |
| 参数 | 无 |
| 2021 版变化 | **新增后向累加和**（从末尾向前累加），与前向共 2 个独立检测项 |
| P_value / Q_value | 正态分布型 |
| 分布类型 | 正态分布型 |

### 3.12 近似熵检测 (Approximate Entropy Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列的复杂度，连续 m 位与 m+1 位模式出现频率之差 |
| 原理 | 比较 m 位和 m+1 位重叠模式的频数差异，计算 ApEn(m)，构造 χ² 统计量 |
| 参数 | **m = 2, m = 5**（2 个独立检测项） |
| P_value / Q_value | 卡方型 |
| 分布类型 | 卡方分布型 |

### 3.13 线性复杂度检测 (Linear Complexity Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列是否可由短 LFSR（线性反馈移位寄存器）生成 |
| 原理 | 用 Berlekamp-Massey 算法计算 N 个 m 位子序列的线性复杂度，与期望分布做 χ² 检验 |
| 参数 | **m = 500, m = 1000**（2021 版新增 m=1000，2 个独立检测项） |
| 备注 | 所有检测项中速度最慢，m=1000 会更慢 |
| P_value / Q_value | 卡方型 |
| 分布类型 | 卡方分布型 |

### 3.14 Maurer 通用统计检测 (Maurer's Universal Statistical Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 序列是否可被有效压缩（信息密度检验） |
| 原理 | 将序列分块后，统计各块与上次出现相同模式的间距之和，与期望值比较 |
| 参数 | **L = 7, Q = 1280** |
| P_value / Q_value | 正态分布型 |
| 分布类型 | 正态分布型 |

### 3.15 离散傅里叶检测 (Discrete Fourier Transform Test)

| 项目     | 说明   |
|--------|--------|
| 检测目的 | 频域中是否存在超过阈值的峰值（周期性特征） |
| 原理 | 对 ±1 序列做 DFT，统计幅度超过阈值 √(n·log(1/0.05)) 的频点数，与期望值比较 |
| 参数 | 无 |
| P_value / Q_value | 正态分布型 |
| 分布类型 | 正态分布型 |

## 六、双重判定准则

### 6.1 一级检测：通过率

- 对 1000 个样本分别计算 P_value
- 统计 P_value ≥ α (0.01) 的样本数
- 要求：≥ **981 个**（即通过率 ≥ 98.1%）

### 6.2 二级检测：分布均匀性（2021 版新增）

- 将 1000 个样本的 **Q_value** 分为 10 个等宽区间
- 对 Q_value 频数分布做 χ² 检验
- 显著性水平 α' = **0.0001**

#### Q_value 计算方法

- **卡方分布型检测**（块内频数、扑克、游程分布、块内最大游程、矩阵秩、近似熵、线性复杂度）：Q_value = P_value（都基于 igamc）
- **正态分布型检测**（单比特频数、重叠子序列、游程总数、二元推导、自相关、累加和、Maurer 通用统计、离散傅里叶）：Q_value = `erfc(V_raw / √2)`，使用统计量的原始值，不取绝对值

### 6.3 最终判定

> 某项检测同时满足一级通过率和二级均匀性 → **该项通过**
> 所有 27 个独立检测项全部通过 → **待检随机数发生器合格**

## 七、2021 版 vs 2012 版关键差异

| 差异点       | 2012 版   | 2021 版     |
|----------|----------|------------|
| 适用范围 | 随机数发生器 | 通用二元序列 |
| 判定体系 | 单一 P_value | P_value + Q_value 双重判定 |
| 块内频数 m | 100 | 10000 |
| 重叠子序列 m | 2, 5 | 3, 5 |
| 块内最大游程 | 仅 1 游程 | 1 游程 + 0 游程 |
| 累加和 | 仅前向 | 前向 + 后向 |
| 游程分布 ei | 理想期望值 | 实际序列总游程计算 |
| 线性复杂度 m | 仅 500 | 500 + 1000 |
| 样本长度 | 仅 10⁶ bit | 20,000 / 10⁶ / 10⁸ 三级 |
| 独立检测项粒度 | 15 种方法 | 明确折算为 27 项 |
| 测试向量 | 无 | 附录 C 提供 |

## 八、检测失败处理建议

当某项检测未通过时，标准建议按以下流程排查：

1. 核查样本采集环境（如量子随机源的温度稳定性）
2. 验证检测参数设置（特别是块长度 m）
3. 执行补充检测（建议优先使用累加和检测）
